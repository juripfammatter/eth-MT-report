\begin{abstract}
    Long-horizon tasks with sparse rewards pose an exploration bottleneck for goal-conditioned reinforcement learning: a policy started from the initial state almost never reaches the goal and receives no learning signal. In locomotion and manipulation, this is usually sidestepped with reference motions, hand-designed curricula, or shaped rewards, each requiring demonstrations or task-specific engineering. Automatic start-state or goal curricula avoid this design burden by generating intermediate tasks, but existing methods typically expand from one side only, proposing goals for a fixed start or start states for a fixed goal, so the full distance to the target must be covered from that single direction.
    We propose BVER\footnote{Project website, videos and code: \url{https://juripfammatter.com/html/bver_demo/bver.html}}, an automatic curriculum that instead expands from both ends at once. Inspired by bidirectional RRT planning, BVER grows a set of start states outward from the goal and a set of goals outward from the initial state distribution, biases each toward unexplored task space, and steers the two toward each other; one goal-conditioned policy is trained on tasks drawn from both sets.
    On sparse-reward quadrupedal box climbing, a task hard enough that no solution emerges without a curriculum, BVER reaches 95\% success in roughly 65\% fewer training iterations than the best demonstration-free baseline, and the resulting policy holds up under wide start, goal, and yaw variation. Ablations confirm that expanding from both ends outperforms either direction alone, and the same curriculum solves sparse-reward point-mass mazes.

\end{abstract}
